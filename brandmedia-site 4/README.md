# Brandmedia — Full Website Prototype

A complete static front-end build based on the approved Brandmedia Stage 1 direction.

## Approved design system

- Font: **Roboto**
- Brand accent: **#F7941D**
- Style: premium editorial / contemporary / restrained
- Core positioning: **Build the Brand. Build the System. Manage the Brand.**

## Included pages

- Homepage
- Brand Strategy & Identity
- Brand Guardian
- Brand Toolkit
- Digital Fast-Track
- Packaging Design
- Work overview
- Reusable Work / Case Study template
- About Brandmedia
- Brand Review
- Insights overview
- Reusable Insights Article template
- Contact
- Privacy placeholder
- Custom 404

Also included:
- Shared responsive design system
- Mobile navigation
- Scroll reveal interactions
- SEO page titles and descriptions
- Sitemap and robots.txt
- Noindex on placeholder templates
- Content editing guides

## Preview locally

From this folder run:

```bash
python3 -m http.server 8080
```

Then open:

`http://localhost:8080`

## Cloudflare Pages

This version has no build step.

- Framework preset: **None**
- Build command: leave blank
- Build output directory: `/`

Upload the folder or connect the project to a Git repository.

## Important before public launch

1. Replace abstract portfolio placeholders with approved Brandmedia client work.
2. Create real case studies using `/work/project-template/`.
3. Replace placeholder Insights topics with final articles as they are written.
4. Connect the Contact form to a proper form/email handler.
5. Review Privacy wording for the final analytics/form setup.
6. Add final social links and any confirmed phone/contact details.
7. Review all copy, pricing and service inclusions before publishing.
